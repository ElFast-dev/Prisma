# Espectro

Espectro es el algoritmo cinematográfico propio de Prisma. Se ejecuta localmente y utiliza datos cinematográficos y experiencias del propietario.

## Entradas

- Géneros y subgéneros disponibles.
- Directores.
- Reparto y equipo.
- Países.
- Fechas y épocas.
- Calificación individual de cada visionado.
- Historial de valoraciones y repeticiones.

## Principios

- No inventar preferencias con datos insuficientes.
- Diferenciar una preferencia declarada de una inferencia.
- Explicar las recomendaciones.
- Excluir películas vistas de los descubrimientos, salvo que exista un modo explícito para recomendar revisiones.
- Versionar el algoritmo.
- Mantener los resultados calculados separados de los datos originales.
- No enviar el historial a servicios externos de IA.

## Evolución prevista

1. Perfil cinematográfico.
2. Afinidades.
3. Puntuación y orden de candidatos.
4. Explicaciones.
5. Evolución temporal y validación.

Los gráficos deben representar relaciones respaldadas por datos reales.

# Seguridad

No publiques credenciales Trakt/TMDB, keystores, tokens, backups, datos personales, historial ni valoraciones reales.

Para informar de una vulnerabilidad, utiliza la función **Private vulnerability reporting** de GitHub en este repositorio. No incluyas detalles explotables en issues públicos.

El motor de recomendaciones está diseñado para procesar perfiles y valoraciones localmente. Los cambios no deben enviar datos personales a servicios externos ni registrar contenido sensible en logs.
